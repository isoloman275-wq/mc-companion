# mc-companion

An **Expo / React Native** mobile companion app for the [Hermes Mission Control](https://github.com/isoloman275-wq/Hermes-MC-Workspace)
3D war-room dashboard. Lets you view live machine/LLM metrics and receive alerts on a phone.

## Stack
- React Native (Expo), EAS Build
- `App.js`, `eas.json`, `plugins/`

## Run / build
```bash
npm install
npx expo start        # dev
eas build --platform android   # release build
```
